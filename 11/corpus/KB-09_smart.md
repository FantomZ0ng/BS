# S.M.A.R.T. і збійні сектори

## Що таке S.M.A.R.T.
S.M.A.R.T. (Self-Monitoring, Analysis and Reporting Technology) — вбудована система самодіагностики жорстких дисків і SSD. Диск постійно рахує помилки читання, перепризначені сектори, години роботи, температуру. Значення читають програмою CrystalDiskInfo, яка показує загальний стан: «Добре» (синій), «Тривога» (жовтий) або «Погано» (червоний).

## Ключові атрибути
- 05 Reallocated Sectors Count — кількість перепризначених (замінених резервними) секторів. Будь-яке ненульове значення, що зростає, свідчить про деградацію поверхні.
- C5 (197) Current Pending Sector Count — сектори, що очікують перепризначення; нестабільні сектори, з яких не вдалося прочитати дані.
- C6 (198) Uncorrectable Sector Count — сектори з невиправними помилками.
- C7 (199) UltraDMA CRC Error Count — помилки передачі; зазвичай несправний SATA-кабель, а не диск.
Для SSD аналогом є атрибути Reallocated Block Count і Wear Leveling Count (знос комірок).

## Симптоми збійних секторів
Жорсткий диск клацає або періодично «зависає» з характерним звуком повторного позиціонування головок, файли копіюються дуже повільно, Windows довго завантажується, з'являються помилки CRC при копіюванні, сині екрани з кодами 0x0000007B або 0x000000EF, повідомлення BOOTMGR is missing через пошкоджену область завантажувача.

## Дії
1. Негайно створіть резервну копію даних користувача (KB-10).
2. Зафіксуйте значення атрибутів 05, C5, C6 у заявці.
3. Перевірка chkdsk C: /r позначає збійні сектори, але на диску, що деградує, може прискорити відмову — спочатку копія.
4. Диск зі статусом «Тривога» або значенням атрибута 05 понад 50 підлягає заміні.
