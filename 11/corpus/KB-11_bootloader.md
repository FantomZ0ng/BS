# Відновлення завантажувача Windows

## Симптоми
Пошкодження завантажувача проявляється повідомленнями BOOTMGR is missing, An operating system wasn't found, No bootable device, Reboot and Select proper Boot device, а також помилкою 0xc000000f у вікні Windows Boot Manager. Причини: невдале оновлення, переривання живлення під час оновлення, встановлення другої ОС, зміна порядку завантаження в BIOS після скидання CMOS.

## Перевірка порядку завантаження
Перш ніж відновлювати завантажувач, увійдіть у BIOS і перевірте, що першим пристроєм завантаження обрано Windows Boot Manager на системному SSD, а режим SATA — AHCI. Після розряду батарейки CMOS (KB-04) порядок завантаження скидається, і це виглядає як пошкодження завантажувача.

## Відновлення
Завантажтеся з інсталяційного USB-накопичувача Windows, оберіть «Відновлення системи» → «Командний рядок» і виконайте:
bootrec /fixmbr
bootrec /fixboot
bootrec /rebuildbcd
Для систем з UEFI та розділом EFI достатньо команди bcdboot C:\Windows /f UEFI. Якщо команда bootrec /fixboot повертає «Відмовлено в доступі», спочатку призначте букву розділу EFI командою diskpart. Після відновлення перевірте диск за S.M.A.R.T. (KB-09): повторне пошкодження часто спричинене збійними секторами.
