# Lab PC Standard Configuration

## Hardware
Standard classroom PC (delivered in 2021, warranty 36 months): motherboard ASUS PRIME B460-PLUS, processor Intel Core i5-10400, memory Kingston 8 GB DDR4-2666 (one module, slot DIMM_A2), system drive Samsung 870 EVO 500 GB SATA SSD, data drive WD Blue 1 TB HDD, graphics card NVIDIA GeForce GTX 1650 4 GB, power supply Chieftec 500 W (80 PLUS Bronze), CPU cooler Deepcool GAMMAXX 400 with a 120 mm PWM fan, CMOS battery CR2032.

## Software
Windows 10 Enterprise LTSC 2021 deployed from the reference image via WDS; updates from the local WSUS server; Microsoft Defender as antivirus. Inventory numbers follow the format LNU-PC-NNNN; the label is on the front panel. BIOS settings profile: SATA mode AHCI, XMP disabled, boot order Windows Boot Manager first, fan curve Standard.
